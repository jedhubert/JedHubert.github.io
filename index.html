LLM servingLLM-Inference-API

Production LLM Inference API

A containerized inference service for TinyLlama 1.1B. FastAPI serves /generate, /health and /cache; Redis caches deterministic answers keyed by a SHA-256 prompt fingerprint plus the model ID, so a repeated prompt skips the model entirely. Ships with one-command deploy scripts, a cron health probe and a troubleshooting playbook.

  • FastAPI
  • Transformers
  • Redis
  • Docker Compose
  • Bash / PowerShell

< 5 ms, down from seconds per call
Eviction

Auth

Ops

Voice AIE-Commerce-Voice-AI-Assistant

Aria, a real-time e-commerce voicebot

A low-latency customer-support agent you talk to in the browser. Audio streams over LiveKit WebRTC into a Python pipeline: Silero VAD, local Whisper speech-to-text, Llama 3.3 70B on Groq, then local Piper text-to-speech. Tool calls look up orders and products, and a small local RAG answers policy questions.

  • faster-whisper
  • Piper TTS
